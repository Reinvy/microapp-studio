MicroApp Studio Architecture

AI-powered local-first micro-app builder — Prompt → Schema → Runner

Frontend Architecture

  • • Next.js 16 App Router + TypeScript
  • • Tailwind v4 + shadcn/ui primitives
  • • @dnd-kit for drag-and-drop builder
  • • Monaco Editor for custom JS nodes
  • • Zustand state management

Engine & Storage

  • • Prompt-to-Schema pattern recognition
  • • Schema engine with field validation
  • • Sandboxed JS evaluator (new Function)
  • • IndexedDB via Dexie.js (local-first)
  • • Zero backend dependencies

Key Features

  • • AI Prompt → Micro App in seconds
  • • Visual drag-and-drop builder
  • • 9 field types: text, number, select, etc.
  • • Custom JavaScript logic nodes
  • • Fully local-first (no server needed)

MicroApp Studio • Built with Next.js + TypeScript + Tailwind CSS • Deployed on Vercel
